# 企业 RAG 分阶段实施清单

这份清单把计划书拆成九个可独立审查的增量。今天计划完成前 3 项：摄入与外发边界的基础能力。完成这 3 项不代表达到企业上线或合规要求。

| 顺序 | 功能增量 | 验收重点 |
| --- | --- | --- |
| 1 | 外部数据传输开关 | 默认阻止上传文档到 MinerU、阻止将检索片段发送给聊天模型；需要分别显式开启。 |
| 2 | 文档治理元数据 | 每份文档登记来源、负责人、密级和审批状态；绝密或未审批文档拒绝入库。 |
| 3 | Chunk 元数据入库 | 文档标识、来源、密级和审批信息随 Chunk 一同存入向量库；缺失元数据时拒绝建索引。 |
| 4 | 身份接入 | 对接企业 OIDC/SSO，并由服务端验证身份；敏感操作接入 MFA。 |
| 5 | 知识库隔离与检索前过滤 | 按业务库隔离集合，查询携带服务端推导的权限过滤条件，补越权测试。 |
| 6 | 审计与追踪 | 查询、召回、生成和拒绝事件关联 Trace ID；日志留存及防篡改依赖独立基础设施。 |
| 7 | 输入输出安全 | 脱敏、提示注入检查、上下文上限、输出敏感信息检查及引用校验。 |
| 8 | 数据同步与删除 | 增量更新、撤回、过期文档清理、版本和索引一致性校验。 |
| 9 | 评估与运维 | 标注集、召回/引用评估、性能与告警、备份及上线验收。 |

当前仓库仍是单机示例。没有 SSO、权限中心、加密存储、独立审计或安全代理；在这些能力完成并通过专项测试前，不应接入真实企业机密数据，也不能宣称满足等保或数据合规要求。
